## Chosen composition

**The case spread and process spine.** Keep cream, forest and editorial serif identity; enlarge working copy and use geometry to change hierarchy. This is a structural redesign, not another color pass.

1. Dashboard: attention counts beside a static, real-count outcome orbit; value/currency caveats form a lower ledger band. Upload remains a real interaction, supporting metrics are subordinate, and the activity table stays sober. No fabricated metric or money calculation.
2. Workspace: compact identity/outcome band, anchored section navigation, source PDF and primary finding aligned at the top of a deliberate split. Reason, backend monetary comparison, owner and action remain immediately exposed. Evidence comes next in a compact grid; further findings/procurement use one native disclosure (automatically open for ambiguous PO alternatives).
3. Decision trace: full-width two-part process map, generous vertical execution spine on the left and an independent business-outcome destination on the right. Use returned states, measured timings and native stage details. Only the actual RUNNING node/connector has ongoing motion. Mobile uses the same readable vertical order.
4. Policy: a full-width connected exploration surface after the recorded decision/evidence and trace. Historical and hypothetical outcomes remain explicitly different; only real API results appear. No financial/evidence/API behavior changes.
